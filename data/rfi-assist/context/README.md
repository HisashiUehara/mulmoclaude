# RFIAssist コンテキストフォルダ

ステップ2（依頼理解 / L1）でAIが「調べる先・聞く先の候補」を出すときに参照する材料。
**空でも動作します**。中身を投入すると候補の精度が上がります。

## サブフォルダ

- `体制表/` — 誰が何の担当か。「聞く先」候補の根拠になります。
  - 例: 組織図、担当者一覧、役割分担表（.md / .csv / .xlsx / .pdf など）
- `過去RFI/` — 過去RFIの実績。類似依頼・定石の根拠になります。
  - 例: 過去の依頼文、回答資料、テンプレート
- `背景/` — プロジェクト背景・目的。依頼の意図理解の根拠になります。
  - 例: プロジェクト概要、目的、スコープ、前提条件

## 空のときの挙動

コンテキストが空の場合、AIは一般的な定石候補（部門横断で当たるべき先）を提示し、
`ai_notes` に「コンテキスト未投入のため一般候補」と明記します。
