# データセンター知識ベース（schema-driven collection）

DC建設・運用に関する知識を、**分野(category)** と **フェーズ(phase)** の2軸で構造化して蓄積する。

## レコード shape

- `id` — kebab-case slug、主キー（ファイル名）。例: `pue-basics`, `uptime-tier`
- `title` — タイトル（必須）
- `category` — 分野（必須 / 下記14分類のいずれか）。**新規追加時は必ず内容から最適な分野を判定して割り当てる**
- `phase` — 案件ライフサイクルのフェーズ（企画・構想 / 設計 / 調達・施工 / コミッショニング / 運用・保守 / 全般）
- `summary` — 1〜2行の要約
- `detail` — 詳細・メモ（markdown）
- `tags` — タグ（カンマ区切り、横断検索用）
- `keywords` — 別名・略語・英語表記など検索の当たりを増やす語
- `importance` — 高 / 中 / 低
- `status` — 下書き / 確認済み
- `source` — 出典・参照
- `createdAt` — 登録日（YYYY-MM-DD）

## カテゴリ（分野）分類ガイド — 自動振り分けの判断基準

情報を登録するときは、内容が最も強く該当する1分野を選ぶ。迷ったら主目的で判断し、`tags` に副次分野を書く。

| category | 含めるもの（例） |
| --- | --- |
| 電気設備 | 受変電、UPS、非常用発電機、蓄電池、PDU、配電、分電盤、力率、瞬停対策 |
| 空調・冷却 | CRAC/CRAH、チラー、冷却塔、外気冷房、液冷、ホット/コールドアイル、気流 |
| 建築・構造 | 建屋、床荷重、フリーアクセス、免震/制震、防水、レイアウト、天井高 |
| ネットワーク・IT基盤 | ラック、キャビネット、構内配線、光/銅ケーブル、MMR、キャリア、サーバ収容 |
| 消防・防災 | 不活性ガス消火、火災感知、VESDA、防火区画、地震/水害対策 |
| 物理セキュリティ | 入退室管理、生体認証、監視カメラ、フェンス、警備、ゾーニング |
| 監視・制御(BMS/DCIM) | BMS、DCIM、EMS、SCADA、アラーム、キャパシティ管理、可視化 |
| 運用・保守 | 保守契約、点検、SLA、MOP/SOP/EOP、シフト、部品在庫、ラウンド |
| 設計・計画 | 容量計画、冗長構成(N+1/2N)、フロアプラン、負荷密度、ロードマップ |
| プロジェクトマネジメント・工程 | BB/FO、クリティカルパス、長納期品、工程表、フェーズ分割、リスク項目、Jardin等の事例 |
| コミッショニング・試験 | Cx、L1〜L5、FAT、IST(統合稼働試験)、耐力試験、成績書、検収 |
| レビュー・品質保証 | レビューの本質、証跡、トレーサビリティ、前提/根拠/責任、承認フロー、チェックリスト |

| 契約・調達 | 発注、見積、ベンダー選定、コロケーション契約、リース、コスト |
| その他 | 上記に当てはまらないもの（用語集、業界動向、社内ルール等） |

## やること

**追加 / 更新** — `manageCollection` putItems。各行はスキーマ検証後に書き込まれる。追加時は `mode: "create"`（id衝突を検知）、既存の一部フィールド更新は `mode: "merge"` で `{ id, 変更フィールド }` のみ渡す（デフォルトの upsert はレコード全体を置換し省略フィールドを消してしまう）。
- **必ず** 内容から `category` と `phase` を判定して埋める（未分類のまま放置しない）。
- 判定に迷う情報は `category: "その他"` にせず、最も近い分野へ入れて `tags` に補足。本当に不明なときのみユーザーに確認。
- 自由記述フィールド（summary/detail）内のダブルクォートは `\"` でエスケープするか、日本語引用符「」を使う。

**一覧 / 参照** — `manageCollection` getItems（大きくなったら `ids`/`fields` で絞る）。

**削除** — レコードファイルを削除。

**スキーマ変更**（分野の追加/改名、フィールド追加など） — `manageCollection` の `schemaDocs` → `getSchema` → `putSchema`。生の schema.json 手編集は不可。

追加・更新後は `presentCollection`（slug と、単体なら record id）で inline 表示し、返ってくる ⚠️ には必ず対処する。
