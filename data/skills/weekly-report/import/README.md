# import/ — 実物レポートの投入場所

ゴールド取込パイプラインの入口。ここに**実物のレポート（.xlsx または .pptx）**を1つ置く。

## 使い方
1. 実物ファイルをこのフォルダに置く（例: `import/weekly-report-2026w14.xlsx`）。
2. 「ゴールド取込を実行して」と依頼する。パイプライン（[../docs/gold-import-pipeline.md](../docs/gold-import-pipeline.md)）が走る。
3. サニタイズ漏れチェックリストが確認画面に出るので、確認して**承認**する。
4. 承認後、**このフォルダの実物ファイルは自動削除**され、削除完了が報告される。

## 重要
- ここに置くのは実データ。**承認後にパイプラインが削除する**まで残る。
- 実データはコミット・共有しないこと（`.gitkeep` 以外は追跡対象外にする想定）。
- NDA未確認の間は実物を置かず、`fixtures/gold/` の仮ゴールド（自作サンプル）で作業する。
