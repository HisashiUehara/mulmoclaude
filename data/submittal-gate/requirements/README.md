# SubmittalGate 要件定義フォルダ

ステップ2（要件照合）でAIが「要件との差分材料」を出すときに参照する材料。
**空でも動作します**。中身を投入すると照合の精度が上がります。

## サブフォルダ

- `OPR/` — Owner's Project Requirements（要件定義書）。照合の一次根拠。
  - 例: 発注者要件、性能要求、環境条件（.md / .csv / .xlsx / .pdf など）
- `仕様基準/` — 仕様書・規格・基準値。型式・寸法・電気特性・互換条件の根拠。
  - 例: 機器仕様、ケーブル規格、コネクタ型式表
- `非互換リスト/` — 既知の非互換の実績。過去の照合で検出した組み合わせをダミー化して置く。
  - Stage 5 の E2E はここのダミーを使って「非互換の検出」を再現する。

## 空のときの挙動

要件が空の場合、AIは一般的な照合観点（型式・寸法・電気特性・互換性）で差分候補を挙げ、
`aiNotes` に「要件未投入のため一般観点」と明記します。**OK/NGの判定はしません**（判定は人間）。
